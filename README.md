# 基金持仓净变动测算（拆股 / 换股折算）

Flask + SQLite 网页应用：上传同一基金前后两期完整持仓 CSV 与换股公告 CSV，
按公告逐日折算期初持仓，按期末代码输出折算来源、折算股数、实报股数与净变动。

## 折算规则

- 公告区间为 **(期初日, 期末日]**：期初日次日起生效，期末日当天含在内；
  期末持仓尚未上传时窗口上不封顶（预览），上传后再约束到期末日。
- 同日、同一旧代码最多一条公告（上传时强校验，违规整表拒绝）。
- 每个交易日先**冻结当日起始余额**，所有折算基于起始余额；
  **新换得的份额当天不再折算**，日内转换在收盘阶段统一结算。
  例如同日 `A→B (1:2)`、`B→C (1:5)`：A 换入的 B 当天保留，
  只有 B 的起始余额被折成 C。
- 全程 `Decimal` 运算，**中间不取整、不截断**；份额以规范化字符串入库。
- 净变动 = 实报股数 − 折算股数；折算侧或实报侧缺项一律按零计算。
- 同一期末代码由多个期初来源合并时，逐来源展示折算路径与份额。

## CSV 格式

持仓 CSV（表头支持中英文别名，证券代码按文本保留前导零）：

```
证券代码,股数
000001,100
000002,200
```

公告 CSV（新旧股数比 = 每 1 股旧代码换得的新代码股数）：

```
生效日,旧代码,新代码,新旧股数比
2026-01-15,000001,000001X,3
```

## 公告整表换报与增量重算

- 公告按整表替换：新表先解析校验，失败仅登记 `failed` 批次，
  原 `active` 表与既有结果完全不动、仍可查询。
- 换报时用代码级轻量模拟（只跟踪代码、不算股数）对比新旧公告，
  **只对可能受改动影响的期初持仓做完整股数重算**，
  未受影响来源沿用上一结果批次的折算行，结果批次中注明重算/沿用条数。
- 公告批次（active / superseded / failed）与全部历史结果批次均可在页面查回。
- 持仓同周期重复上传按整表替换，自动触发全量重算；历史持仓文件保留。

## 本地运行

```bash
pip install -r requirements.txt
python run.py            # http://127.0.0.1:8000
```

## Docker Compose 启动

```bash
docker compose up --build -d
# 打开 http://localhost:8000
```

SQLite 数据库与上传的原始 CSV 持久化在命名卷 `fund-data`（容器内 `/data`）。
单 gunicorn worker + 多线程，配合 SQLite WAL。

## 测试

```bash
python -m pytest tests/ -q
```

覆盖：折算引擎（拆股、日期边界、同日链、合并、不取整）、
服务层（净变动缺项按零、换报增量、换报失败可查、重复代码拒绝）、
网页端到端（上传、换报、flash 提示）。

## 目录

```

app/services.py    上传/换报/增量重算/净变动查询
app/routes.py      网页路由
app/templates/     单页界面
tests/             pytest 测试
```
